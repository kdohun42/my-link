# 📱 [와이어프레임] 마이링크 메인 화면 (방문자 뷰)

> **문서 대상**: 일반 방문자(팬, 클라이언트, 채용 담당자)가 모바일/PC 브라우저로 접속했을 때 보게 되는 메인 화면 구조  
> **기준 레이아웃**: 스마트폰 친화적 모바일 뷰 (`max-w-md`, 너비 약 390px ~ 430px 중앙 정렬)

## 2. 화면 구역별 상세 컴포넌트 명세

| 구역 | 컴포넌트명 | 설명 및 인터랙션 |
| :--- | :--- | :--- |
| **0. 탑 배너** | `NoticeBanner` | • 화면 최상단 고정 띠배너<br>• 핵심 공지사항 태그 및 이메일 문의 바로가기 링크 |
| **0. 시연 바** | `ThemeQuickSwitcher` | • 시연용 3가지 테마(Clean Light, Onyx Dark, Sunset) 원클릭 토글 버튼 |
| **1. 헤더** | `ProfileHeader` | • **아바타**: 80px 원형 고화질 프로필 이미지 + 우하단 온라인 녹색 뱃지<br>• **이름 & 타이틀**: 볼드 헤드라인 + 라운드 뱃지 태그<br>• **소개글(Bio)**: 최대 2~3줄의 간결한 소개 카피 |
| **2. SNS 바** | `SocialIconBar` | • 인스타그램, 유튜브, 깃허브, X, 이메일 원형 버튼<br>• 마우스 호버 시 살짝 떠오르는(Scale-up) 모션 |
| **3. 링크 목록** | `LinkCardList` | • **구성**: 좌측 썸네일/아이콘 + 중앙 볼드 제목 및 서브 설명 + 우측 화살표<br>• **인터랙션**: 호버 시 배경색 반전 및 쉐도우 효과, 탭 시 새 탭 URL 오픈 |
| **4. 미디어** | `YoutubeEmbedCard` | • 16:9 비율 유지 유튜브 iframe 반응형 카드<br>• 프로필을 벗어나지 않고 영상 시청 가능 |
| **5. 액션 영역** | `ActionSection` | • **이메일 복사 버튼**: 클릭 시 클립보드에 이메일 복사 + 화면 하단 토스트 팝업<br>• **응원하기(부스트) 버튼**: 클릭 시 카운터 +1 증가 및 펄스 하트 애니메이션 |
| **6. 푸터** | `ProfileFooter` | • 마이링크 오픈소스 브랜딩 안내 및 깃허브 링크 |

## 3. 뷰포트 반응형 처리 기준
- **모바일 (360px ~ 480px)**: 1열 전체 너비 채움 (`w-full px-4`), 버튼 및 텍스트 터치 타겟 최소 44px 이상 확보
- **태블릿 / PC (640px 이상)**: 브라우저 정중앙에 스마트폰 비율의 모바일 카드 프레임(`max-w-md`, 약 420px)으로 렌더링되며, 배경에는 은은한 캔버스 여백 형성
